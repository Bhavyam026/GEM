# SocialDesk Demo Admin Dashboard

A standalone, browser-only admin dashboard prototype for fictional sample users.

## Run locally
Open `index.html` in a modern browser. No build step or server is required.

## Demo sign-in
- Username: `demo-admin`
- Password: `Demo@123`

## Included
- Demo admin sign-in and sign-out
- Fictional user directory
- Simulated active sessions with end-session controls
- Demo security event log
- Responsive overview dashboard

## Safety and scope
This is an independent demo and is not affiliated with Instagram or Meta. It does not connect to Instagram, collect real Instagram credentials, capture OTPs, or bypass authentication. Demo sign-in state uses browser session storage; sample data is held in page memory. This is a front-end prototype, not production authentication or a multi-user backend.
