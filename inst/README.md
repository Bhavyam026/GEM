## Workflow
1. Draft the concept and copy.
2. Prepare/attach the actual creative media.
3. Review text, contact details and visual quality.
4. Schedule through the connected publishing tool only after media is available and the schedule is confirmed.
5. Update the CSV status only after the platform confirms the action.

Note: This GitHub folder stores content planning and text. It does not itself publish to Instagram. Publishing requires a supported connected account and actual media files/URLs.
